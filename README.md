# Chizuru

星流插件。

## 功能

**将歌词送至星河岛**

播放器获取的歌词经 LyricON 的「歌词提供者」协议交付星流，由星河岛歌词胶囊显示，已适配逐字歌词与翻译。

酷狗音乐与酷狗概念版另行实现歌词文件读取；酷我音乐自行解析缓存并结合播放器回调；播放器进程被系统结束后，可在 root 环境下由本插件作为独立提供者继续供词，读取播放状态与歌词缓存。

**识别剪贴板内容并送至星河岛**

复制链接、电话号码或地址后，卡片将出现在星河岛，点击卡片可自动打开浏览器、拨号、短信或地图。

## 使用方法

1. 安装 APK，并在 LSPosed 中启用 Chizuru。
2. 按需勾选作用域：
   - 使用歌词胶囊：勾选需要放歌的播放器；
   - 使用链接助手：勾选「系统框架」。
3. 勾选完成后，将对应应用停止运行一次。若勾选的是「系统框架」，请重启系统框架。

## 网络与隐私

Chizuru 未申请网络权限，不联网、不上传、不统计。歌词优先从本机读取；仅在无法读取时，于被勾选的播放器进程内进行一次只读的网络旁路嗅探。

## 关于酷我与汽水音乐

酷我音乐与汽水音乐仅在检测到无线音频输出时输出歌名与歌手，未检测到时星河岛将不显示歌词。

为此，本插件在这两个播放器的进程内将以下两个查询方法的返回值调整为 true：

- `AudioManager#isBluetoothA2dpOn()`
- `BluetoothAdapter#isEnabled()`

本插件不会连接、开启或搜索任何蓝牙设备，不申请蓝牙权限，不修改播放器的设置与数据，播放行为保持不变。关闭歌词能力后即恢复原状。

如不接受此做法，可取消勾选这两个播放器，或在插件内关闭歌词胶囊。

除上述两个方法外，插件对播放器一律只读。

## 剪贴板

链接助手在系统进程内监听复制操作，仅处理可判定为链接的文本，其余内容不予处理。日志中的链接一律隐去。

## root（可选）

- **独立歌词提供者**：通过 `dumpsys media_session` 读取播放状态，并读取播放器自身的歌词缓存，均为只读操作。
- **音理音理适配**：仅修改其一项设置值 `lyricon_enabled`（由 false 改为 true），写入后回读确认。

未开启 root 亦可正常使用，歌词胶囊与链接助手均不依赖 root。
