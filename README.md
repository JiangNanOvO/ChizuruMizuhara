# Chizuru

    星流插件

公益请勿倒卖

## 它干的事

**把歌词送到岛上**

播放器自己拿到的词 经过LyricON的「歌词提供者」协议交给星流 剩下的交给星河岛歌词胶囊去显示 逐字歌词和翻译都已适配

酷狗、酷狗概念版另写了条歌词文件直挂；酷我是自己解缓存 再搭播放器的回调

播放器进程被清了的情况 开了root可以让**Chizuru**自己顶上去供词 读播放状态、歌词缓存

**复制链接就上岛**

复制一段链接 卡片自己出来 点卡片自动跳转浏览器

**复制手机号就上岛**

复制手机号 卡片自己出来 点卡片自动跳转拨号或短信(可选)

**复制地址就上岛**

复制一段地址 卡片自己出来 点卡片自动跳转系统默认地图或自定地图

## 怎么用

装APK 进LSPosed勾上Chizuru

作用域按需要来：

- 想用歌词胶囊=勾你要放歌的那个播放器
- 想用链接助手=勾「系统框架」

勾完把那几个应用重启一下 如是系统框架=星流重启作用域

## 联网不联网

Chizuru本体没申请网络权限 不联网、不上传、不统计 歌词本机读取 如果实在拿不到才在被勾的那个播放器里做一次只读的旁路嗅探

## 酷我和汽水

这两个播放器有个毛病 它以为你在用无线输出的时候 才肯把歌名、歌手吐出来 不这么以为就装死 星河岛那边一片空白 胶囊对它们等于没用

所以我在它们进程里把
 `AudioManager#isBluetoothA2dpOn()`
   和
 `BluetoothAdapter#isEnabled()` 
 这两个查询方法改成返回 true

但是 不连、不开、不搜任何蓝牙设备 不要蓝牙权限 不动它们的设置和数据 播放行为不变 关掉歌词能力 立刻恢复原样

不想这样也行 去掉对这两个播放器的勾选 或者在模块里把歌词胶囊关掉 它就再也不会冒出来

除了这两个方法 模块对播放器一律只读

## 剪贴板

链接助手在系统进程里听复制 只处理认得出是链接的文本 不带链接的当场扔掉 日志里链接一律打码

## root（可选）

  **独立歌词提供者**：`dumpsys media_session` 读播放状态 再读播放器自己的歌词缓存 全只读
- **音理音理适配**：只改它一个设置值 `lyricon_enabled`从false → true 写完回读确认

不开root也能用 歌词胶囊和链接助手都不需要
