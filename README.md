# Chizuru

> 星流（AstraFlow）· 星河岛的插件：把**正在播放的歌词**、以及**复制内容里的链接、手机号、地址**送上岛。

LSPosed 模块 · 应用名 **Chizuru** · 包名 `com.astraflow.Chizuru`（技术标识，不影响显示）· 免费公益，禁止倒卖与付费代装

---

## 功能

| 能力 | 说明 | 需要什么 |
| --- | --- | --- |
| **歌词胶囊** | 按 LyricON「歌词提供者」协议，把播放器已经拿到的歌词推给星流，由星河岛原生胶囊呈现（支持逐字歌词、翻译）。酷狗 / 酷狗概念版另有「歌词文件直挂」，酷我另有「缓存直解 + 播放器内部回调」通道 | 作用域勾选目标播放器 |
| **独立歌词提供者** | 播放器进程被清掉时接管供词：读播放器的播放状态与它自己的歌词缓存，直接推给星流 | root（可选） |
| **链接、地址、手机号助手** | 复制到带链接、手机号、地址的内容就上岛；点卡片由**星河岛自己**打开浏览器、地图、拨号、短信，不依赖本应用进程（进程被杀也照常打开） | 作用域勾选「系统框架」 |

---

## 安装

1. 安装 APK；
2. 在 LSPosed 里**启用模块**，作用域勾选：
   - 你想用歌词胶囊的**播放器本体**（网易云 / QQ 音乐 / 酷狗 / 酷我 / 汽水 / 波点 / MeloYou / 洛雪 / 音理音理…）；
   - 以及**系统框架**（链接助手需要）；
3. 重启被勾选的应用（或重启手机）。

## 权限与隐私

**关于网络**：应用本体**不申请网络权限**，不联网、不上传、不统计。歌词只在设备本地取用；
取不到时只在被勾选的应用进程内做**只读**的网络歌词嗅探。

**关于音频输出状态适配（唯一一处非只读改动，仅酷我 / 汽水音乐）**：

| 项 | 说明 |
| --- | --- |
| 改什么 | 在 `cn.kuwo.player`、`com.luna.music` 两个应用进程内，让 `AudioManager#isBluetoothA2dpOn()` 与 `BluetoothAdapter#isEnabled()` 这两个**查询方法**返回 true |
| 为什么 | 这两个播放器只在「检测到正在使用无线音频输出」时才上报完整的媒体信息（歌名 / 歌手 / 时长）；否则星河岛拿不到歌名，歌词胶囊对它们完全不可用 |
| 不改什么 | 不连接、不开启、不搜索任何蓝牙设备，不申请任何蓝牙权限，不修改播放器的设置与数据，不改变播放行为；歌词能力关闭时立刻恢复原返回值（走原始实现） |
| 怎么关掉 | 在 LSPosed 里去勾这两个播放器的作用域，或在模块里关闭「歌词胶囊」，它就不再生效 |

除上述两处方法外，模块对播放器**只读**：不修改播放器行为、不写入播放器数据。

**关于剪贴板**：链接助手在系统进程里旁路监听复制动作。**只有识别出链接的文本才会被处理**；
不含链接的内容会**立即丢弃**，不写入任何字段、不落盘。日志中的链接一律打码，不记录完整链接。

**关于 root（两项，均可不开）**：

| 功能 | 用 root 做什么 |
| --- | --- |
| 独立歌词提供者 | 只读：`dumpsys media_session` 取当前播放状态；读取播放器自己的歌词缓存文件 |
| 音理音理适配 | 修改「音理音理」的**一个**设置值（`lyricon_enabled`：false → true）。改前备份、结构不符即放弃、写完回读校验 |

本应用**不会**写入开机脚本、**不会**修改系统电池白名单或省电设置、**不会**改动其它任何应用的数据。
不开 root 也完全可用：歌词胶囊（作用域方式）与链接助手都不需要 root。
